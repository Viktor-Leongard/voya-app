# voya-app

Public website for **Voya** — privacy policy and support pages, served via GitHub Pages.

- Home: https://viktor-leongard.github.io/voya-app/
- Privacy Policy: https://viktor-leongard.github.io/voya-app/privacy.html
- Support: https://viktor-leongard.github.io/voya-app/support.html

Static HTML, no build step. Edit the `.html` files and push to `main`; Pages
redeploys automatically. The app source lives in a separate (private) repository.
